# 随机塔防微信小游戏

一个微信小游戏塔防原型，入口为根目录 `game.js` 和 `game.json`，包含随机地图、分轮出兵、建塔、升级和基础胜负循环。

## 玩法

- 四种基础塔：箭塔、火箭塔、兵营、魔法塔。
- 地图使用 18 x 20 的细格子，随机路线会横向或纵向蛇形折返，并穿插随机短折线；路线不会自交，路线之间会尽量拉开间距，给 2 x 2 塔留下建造空间。
- 每座塔占用 2 x 2 格，建造时需要完整空地，不能压住道路或其他塔。
- 建塔交互为先点击地图空地，再直接在地图上的弹出菜单里选择具体塔；点击已有塔查看属性并升级。
- 选中已建造的塔后可以出售，返还该塔总投入金币的 60%。
- 塔的攻击覆盖范围已收窄，兵营防区也同步缩小。
- 火箭塔造成范围伤害，兵营会派出士兵，魔法塔会减速敌人。
- 兵营士兵只在附近防区巡逻，每个士兵最多阻挡 1 个敌人，并对被阻挡敌人造成少量持续伤害。
- 兵营士兵使用独立卡通 PNG 图标，出生时有弹出光圈动画，血量归零后播放图标残影和消散动画，再等待一段时间重新生成。
- 被阻挡的敌人会攻击士兵，士兵血量归零后消失，兵营等待一段时间后会重新派兵。
- 敌人包含步兵、疾行兵、重甲兵和幽影兵：疾行兵速度快但血少，重甲兵速度慢但血厚，幽影兵会无视兵营阻挡；不同敌人使用高区分度颜色和标记显示。
- 每 3 轮会有一个高血量 Boss 混在敌人队伍里出现。
- 提供两个带冷却时间的技能：冻结全场敌人、短时间内攻击力提升 50%。
- 冻结技能会覆盖全场冰霜蒙层和漂浮冰晶；强攻技能只在塔和士兵身上叠加火焰、橙色光晕和火星效果。
- 敌人每一轮都会获得更高生命值，后续轮次压力会逐步提升。
- 四类塔都有不同的 Canvas 外观，攻击时带有炮口、箭矢、火箭、魔法光束等动画。
- 四种塔和主要敌人使用 `assets/icons/` 下的俯视卡通 PNG 图标，图片加载失败时会回退到 Canvas 绘制。
- 道路显示加宽并带亮色中心线；敌人显示尺寸放大，沿随机路线移动并带有摆动/压缩动作，被攻击时闪烁并出现命中特效，死亡时播放图标残影、消散粒子和冲击波。
- 炮台攻击带有后坐力、炮口闪光；火箭弹带尾焰，命中后会播放范围爆炸和碎片动画。
- 生命归零后会弹出 Game Over 结算，展示坚持轮次、消灭敌人、赚取金币、花费金币等战果。
- 小游戏界面会读取 iPhone 安全区，整体下移避开刘海、灵动岛和底部 Home Indicator。
- 点击“随机地图”会重新开始一局随机地图，并重置金币、生命、轮次、技能冷却和结算统计；如果当前已经有游玩进度，会先弹出确认提示。
- 点击“开始第 N 轮”刷出一轮敌人；本轮敌人全部出现后，即使场上还有敌人，也可以点击“提前开始第 N 轮”追加下一轮，并根据预计提前清场时间发放一笔金币奖励。
